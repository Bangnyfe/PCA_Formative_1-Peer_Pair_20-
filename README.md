# Formative 2 PCA- Peer Pair 20

## Project Overview

This project implements Principal Component Analysis (PCA) from scratch using NumPy on agricultural production data from Rwanda. The dataset contains plot-level information from the 2023/2024 Seasonal Agricultural Survey, including plot size, crop production, sales, household consumption, storage, and crop losses.

We cleaned and standardized the data, handled missing and non-numeric values, calculated the covariance matrix, performed eigendecomposition, selected principal components based on explained variance, and visualized the data before and after PCA.

## Dataset

The dataset was obtained from the Rwanda Open Data Portal:

https://data.gov.rw/datasets/14191c4f-9b3d-4ef5-85c3-49ffeafd50b9?tab=metadata
